# 🤖 Aether AI

A modern AI chatbot built using Python, Streamlit, and Google Gemini AI with a clean beige glassmorphism interface inspired by modern productivity applications.

## 🚀 Live Demo

**Try it here:**

https://aether-ai-qqo2mgj5epqgzdege7xvax.streamlit.app/

## ✨ Features

* AI-powered conversations using Google Gemini
* Elegant beige and brown glassmorphism UI
* Modern dotted background design
* Chat history support
* Responsive web interface
* Streamlit deployment
* Secure API key management using Streamlit Secrets

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini AI
* HTML/CSS
* Python Dotenv

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/AaryanDev9871/Aether-AI.git
cd Aether-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application:

```bash
python -m streamlit run app.py
```
